## Рабочий стол

**Рабочий стол - является описанием того, как должен быть организован рабочий стол.**

Идея появилась из того, что мне нравится структурировать рабочий стол, но без строго формата каждый раз появляются новые папки и подпапки, от чего структура перестаёт быть такой строгой, поэтому здесь было сделано своего рода дерево файлов, которые показывают, как всё должно выглядеть.

---

### Организация:

<!-- ╴│├└ -->

```txt
Рабочий стол/ - директория рабочего стола
├╴GitHub/ - организация всего, что связано с GitHub
│ ├╴Projects/ - проекты GitHub, которые не относятся к экосистеме
│ │ ├╴Open/ - репозитории, которые активно ведутся
│ │ └╴Closed/ - репозитории, которые уже были завершены
│ ├╴Sandbox/ - Полигон
│ ├╴Modules/ - Модули
│ └╴MichiTheCat-RedStar/ - репозиторий с основной информацией
├╴GitHub.desktop - ярлык с URL на мой профиль GitHub
├╴MyProjects/ - под проекты, которые не для GitHub, вроде учёбы или работы, может хранить внутри отдельно ForWork/ и ForMe/
├╴Something/ - временные папки и файлы, например данные с флешки
├╴MyFiles/ - для остальных файлов (внутри обычно ISO/, Furrys/, Cartoons/ и прочее)
└╴Steam.desktop - запуск Steam
```

Это представление *минимального набора* на рабочем столе. Здесь в основном показан упор на `GitHub/` - указывает, что я хочу зависеть не от локального диска, а от облачного хранилища в виде GitHub (однако это не исключает то, что я копирую порой данные на внешний накопитель из-за как недоверия облачным хранилищам, так и по иным причинам страха потери данных).
