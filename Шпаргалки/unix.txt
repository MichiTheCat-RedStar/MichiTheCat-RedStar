	--- ОСНОВНЫЕ КОМАНДЫ UNIX ---

 = Навигация и файлы:

- Показать текущую директорию:

pwd


- Перейти в директорию:

cd <путь>


- Листинг содержимого:

ls						# обычный список


- Листинг с подробностями:

ls -l					# права, владелец, размер


- Листинг со скрытыми файлами:

ls -la


- Копировать файл/папку:

cp <источник> <назначение>


- Переместить/переименовать:

mv <источник> <назначение>


- Удалить файл:

rm <файл>


- Удалить папку рекурсивно:

rm -rf <папка>


- Создать папку:

mkdir <имя>


- Создать папку с промежуточными:

mkdir -p <путь/с/вложенными>


- Просмотр содержимого файла:

cat <файл>				# весь файл сразу


- Просмотр с пагинацией:

less <файл>				# постранично


 = Процессы:

- Показать запущенные процессы:

ps						# только свои


- Все процессы пользователя:

ps -u <user>


- Дерево процессов:

ps auxf


- Завершить процесс по PID:

kill <PID>


- Принудительно завершить:

kill -9 <PID>


- Интерактивный монитор:

top


 = Права доступа:

- Изменить права (числовой режим):

chmod 755 <файл>


- Изменить права (символьный):

chmod u+x <файл>


- Изменить владельца:

chown <пользователь> <файл>


- Изменить группу:

chgrp <группа> <файл>



	--- ПОЛНАЯ ШПАРГАЛКА ПО UNIX ---

 = Файловая система (расширенно):

- Вывести текущий путь:

pwd


- Перейти в домашнюю папку:

cd ~


- Перейти в предыдущую папку:

cd -


- Показать только папки:

ls -d */


- Показать информацию о дисках:

df -h					# в человекочитаемом виде


- Показать размер папки/файла:

du -sh <путь>


- Найти файлы по имени:

find <путь> -name "<имя>"


- Найти файлы по типу:

find <путь> -type f		# файлы, -type d для папок


- Поиск текста в файлах:

grep "<текст>" <файл>	# в одном файле


- Рекурсивный поиск в папке:

grep -r "<текст>" <папка>


- Просмотр первых строк:

head -n 10 <файл>


- Просмотр последних строк:

tail -n 10 <файл>


- Следить за логом в реальном времени:

tail -f <файл>


 = Работа с процессами (расширенно):

- Показать все процессы с полной инфой:

ps aux


- Дерево процессов с иерархией:

pstree


- Завершить процесс по имени:

pkill <имя>


- Запустить процесс в фоне:

<команда> &


- Показать фоновые задачи:

jobs


- Вернуть задачу на передний план:

fg %<номер>


- Приоритет процесса (запуск с низким приоритетом):

nice -n 10 <команда>


- Изменить приоритет работающего:

renice -n 10 <PID>


 = Сеть:

- Показать сетевые интерфейсы:

ip addr					# или ifconfig (устаревшее)


- Пинговать хост:

ping <хост>


- Показать таблицу маршрутизации:

ip route				# или route -n


- Посмотреть открытые порты:

ss -tulnp				# или netstat -tulnp


- Скачать файл (http/ftp):

wget <url>


- Скачать с продолжением:

wget -c <url>


- Копирование по SSH:

scp <файл> user@host:/путь


 = Архивация и сжатие:

- Создать tar-архив:

tar -cvf archive.tar <файлы/папки>


- Распаковать tar:

tar -xvf archive.tar


- Сжать с gzip:

tar -czvf archive.tar.gz <файлы>


- Распаковать .tar.gz:

tar -xzvf archive.tar.gz


- Сжать с bzip2:

tar -cjvf archive.tar.bz2 <файлы>


- Распаковать .tar.bz2:

tar -xjvf archive.tar.bz2


- Просто сжать файл gzip:

gzip <файл>				# получится <файл>.gz


- Распаковать gzip:

gunzip <файл>.gz


 = Управление пользователями и системой:

- Посмотреть кто залогинен:

who


- Посмотреть текущего пользователя:

whoami


- Сменить пользователя:

su - <имя>


- Выполнить команду с правами root:

sudo <команда>


- Перезагрузить систему:

sudo reboot


- Выключить систему:

sudo poweroff


- Посмотреть версию ядра:

uname -a


- Посмотреть загрузку системы:

uptime


 = Переменные и окружение:

- Показать переменные окружения:

env


- Показать конкретную переменную:

echo $HOME


- Установить переменную (временная):

export MY_VAR=значение


- Удалить переменную:

unset MY_VAR


 = Дополнительные полезные команды:

- Показать историю команд:

history


- Повторить последнюю команду:

!!						# или !!


- Повторить команду с номером из истории:

!123


- Показать справку по команде:

man <команда>			# или --help


- Очистить терминал:

clear


- Вывести дату и время:

date


- Подсчитать строки/слова/байты:

wc <файл>


- Сортировка:

sort <файл>


- Уникальные строки (без дубликатов):

uniq <файл>
