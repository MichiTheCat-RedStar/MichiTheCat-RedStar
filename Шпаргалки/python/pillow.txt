	--- ОСНОВЫ PILLOW ---

 = Назначение:

- Обработка изображений:

# Pillow — библиотека для работы с изображениями
# Форк PIL (Python Imaging Library), развитие которого прекратилось
# Поддерживает открытие, создание, редактирование, сохранение
# Работает с JPEG, PNG, BMP, GIF, TIFF, WebP и другими форматами


 = Установка:

- Через pip:

pip install Pillow


- Проверка версии:

import PIL
print(PIL.__version__)


 = Импорт:

- Основные модули:

from PIL import Image			# ядро: открытие, создание, сохранение
from PIL import ImageDraw		# рисование на изображении
from PIL import ImageFont		# шрифты для текста
from PIL import ImageFilter		# предопределённые фильтры
from PIL import ImageEnhance	# яркость, контраст, цвет, резкость
from PIL import ImageOps		# вспомогательные операции
from PIL import ImageColor		# преобразование имён цветов в RGB
from PIL import ExifTags		# теги EXIF

 = Конвертация:

 = Режимы:

# "1" — 1-бит, чёрно-белый
# "L" — 8-бит, градации серого
# "P" — 8-бит, палитра
# "RGB" — 3x8-бит, цветной
# "RGBA" — 4x8-бит, цветной с альфа-каналом
# "CMYK" — 4x8-бит, для печати
# "YCbCr" — 3x8-бит, JPEG
# "LAB" — 3x8-бит, L*a*b*
# "HSV" — 3x8-бит, Hue, Saturation, Value
# "I" — 32-бит, целое
# "F" — 32-бит, с плавающей запятой

	--- СОХРАНЕНИЕ И ФОРМАТЫ ---

 = Сохранение:

- save():

img.save("output.png")
img.save("output.jpg", "JPEG", quality=85)
img.save("output.webp", "WEBP", quality=80, method=6)
img.save("output.png", "PNG", optimize=True)


 = Параметры JPEG:

img.save("out.jpg", "JPEG", quality=85, optimize=True, progressive=True)
# quality: 0–100 (выше — лучше качество, больше файл)
# optimize: True — оптимизация Хаффмана
# progressive: True — прогрессивный JPEG


 = Параметры PNG:

img.save("out.png", "PNG", optimize=True, compress_level=9)
# compress_level: 0–9 (9 — максимальное сжатие)


 = Параметры WebP:

img.save("out.webp", "WEBP", quality=80, method=6, lossless=False)
# method: 0–6 (6 — максимальное сжатие, медленно)


 = Конвертация формата:

img = Image.open("input.png")
img.convert("RGB").save("output.jpg", "JPEG", quality=85)

# JPEG не поддерживает прозрачность — нужен convert("RGB")

 = Частые ошибки:

- Забыли convert("RGB"):

# JPEG не поддерживает RGBA
# Ошибка: cannot write mode RGBA as JPEG


- Ресурсы не освобождены:

# Используйте with Image.open() as im:


- Большие изображения:

# Image.open() ленив, но load() читает всё в память
# Для огромных изображений используйте draft()


- Потеря EXIF:

# При сохранении EXIF не передаётся автоматически
# Сохраняйте вручную: img.save("out.jpg", exif=img.info.get("exif"))
