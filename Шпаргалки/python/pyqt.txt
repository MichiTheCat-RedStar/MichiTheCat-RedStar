	--- ОСНОВНЫЕ КОМАНДЫ PYQT (PYQT5) ---

 = Установка:

- Установить PyQt5:

pip install PyQt5


- Установить PyQt6 (альтернатива):

pip install PyQt6


 = Импорт и создание приложения:

- Импорт основных модулей:

from PyQt5.QtWidgets import QApplication, QWidget, QLabel, QPushButton, QVBoxLayout


- Создать приложение (экземпляр QApplication):

app = QApplication([])


- Создать главное окно (виджет):

window = QWidget()
window.setWindowTitle('Моё приложение')
window.resize(400, 300)


- Показать окно:

window.show()


- Запустить главный цикл событий:

app.exec_()					# в PyQt5
# app.exec()				# в PyQt6


 = Основные виджеты:

- Метка (QLabel):

label = QLabel('Текст')


- Кнопка (QPushButton):

button = QPushButton('Нажми меня')


- Однострочное поле ввода (QLineEdit):

line_edit = QLineEdit()
line_edit.setPlaceholderText('Введите текст')


- Многострочное поле (QTextEdit):

text_edit = QTextEdit()


- Флажок (QCheckBox):

checkbox = QCheckBox('Опция')


- Радиокнопка (QRadioButton):

radio1 = QRadioButton('Вариант 1')
radio2 = QRadioButton('Вариант 2')


 = Макеты (Layouts):

- Вертикальный макет (QVBoxLayout):

layout = QVBoxLayout()
layout.addWidget(label)
layout.addWidget(button)
window.setLayout(layout)


- Горизонтальный макет (QHBoxLayout):

from PyQt5.QtWidgets import QHBoxLayout
h_layout = QHBoxLayout()


- Сетка (QGridLayout):

from PyQt5.QtWidgets import QGridLayout
grid = QGridLayout()
grid.addWidget(widget, row, column, rowspan, colspan)


 = Сигналы и слоты (обработка событий):

- Подключить сигнал clicked к функции:

button.clicked.connect(on_button_click)


- Определить функцию-обработчик:

def on_button_click():
    print('Кнопка нажата')


- Сигнал textChanged для QLineEdit:

line_edit.textChanged.connect(on_text_changed)


- Сигнал currentIndexChanged для QComboBox:

combo.currentIndexChanged.connect(on_combo_changed)


 = Диалоговые окна:

- Информационное сообщение:

from PyQt5.QtWidgets import QMessageBox
QMessageBox.information(window, 'Заголовок', 'Сообщение')


- Предупреждение:

- Вопрос (Yes/No):

    pass

 = Виджеты (подробно):

- QLabel — метка:

label = QLabel('Текст')
label.setAlignment(Qt.AlignCenter)			# выравнивание
label.setPixmap(QPixmap('image.png'))		# изображение


- QPushButton — кнопка:

btn = QPushButton('Текст')
btn.setIcon(QIcon('icon.png'))
btn.setShortcut('Ctrl+O')					# горячая клавиша


- QLineEdit — однострочное поле:

line.setEchoMode(QLineEdit.Password)		# режим пароля

- QTextEdit — многострочное поле:

text_edit = QTextEdit()

- QComboBox — выпадающий список:

combo.addItems(['Пункт 1', 'Пункт 2'])
combo.addItem('Пункт 3')

- QCheckBox — флажок:

check.setChecked(True)

check.stateChanged.connect(on_check)		# передаёт int (2 — включено, 0 — выключено)


- QRadioButton — радиокнопка (группируются автоматически в одном родителе):

- QSpinBox / QDoubleSpinBox — счётчики чисел:

- QSlider — ползунок:

- QProgressBar — индикатор прогресса:

progress.setValue(50)


- QListWidget — список:

- QTableWidget — таблица:

 = События (переопределение методов):

- Обработка закрытия окна:

def closeEvent(self, event):
    reply = QMessageBox.question(self, 'Выход', 'Вы уверены?', QMessageBox.Yes | QMessageBox.No)
    if reply == QMessageBox.Yes:
        event.accept()
    else:
        event.ignore()


- Обработка нажатия клавиш:

def keyPressEvent(self, event):
    if event.key() == Qt.Key_Escape:
        self.close()
    elif event.modifiers() == Qt.ControlModifier and event.key() == Qt.Key_S:
        self.save()

- Использование QThread для многопоточности (не блокировать GUI):

class Worker(QThread):
    finished = pyqtSignal()
    def run(self):
        # долгая работа
        self.finished.emit()

worker = Worker()
worker.finished.connect(on_finished)
worker.start()


 = Отличия PyQt5 и PyQt6:

- exec_() → exec() (PyQt6 использует exec)
- QVariant удалён (используйте стандартные типы Python)
- Некоторые enum перемещены из Qt в соответствующие классы (например, Qt.AlignCenter → Qt.AlignmentFlag.AlignCenter)
- Импорт: PyQt6.QtWidgets и т.д.

По возможности используйте PyQt5 для стабильности, если не требуется новая функциональность.


 = Советы:

- Всегда используйте QApplication([]), даже если аргументы не нужны.
- Для предотвращения зависания интерфейса используйте QThread или QTimer для фоновых задач.
- В сложных проектах используйте Qt Designer для создания .ui файлов и загружайте их через uic.loadUi.
- Используйте QSS для кастомизации внешнего вида без переопределения стилей в коде.
