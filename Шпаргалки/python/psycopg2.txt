 = Транзакции в psycopg2:

- Ручное управление:

conn = psycopg2.connect(...)
conn.autocommit = False		# по умолчанию

try:
    cur = conn.cursor()
    cur.execute("INSERT ...")
    cur.execute("UPDATE ...")
    conn.commit()
except Exception:
    conn.rollback()
finally:
    cur.close()
    conn.close()


- Контекстный менеджер (автоматический commit/rollback):

with conn:
    with conn.cursor() as cur:
        cur.execute("INSERT ...")
        cur.execute("UPDATE ...")
# при выходе без ошибок — commit, при ошибке — rollback


- Установка уровня изоляции:

conn.set_isolation_level(
    psycopg2.extensions.ISOLATION_LEVEL_SERIALIZABLE
)

 = SQLAlchemy ORM:

- Определение модели:

from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

class Base(DeclarativeBase):
    pass

class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str]
    email: Mapped[str | None]


- Создание таблиц:

- Сессия:

    session.commit()


- Запрос через ORM:

- SQLAlchemy 2.0 стиль (select):

 = Обработка ошибок:

- psycopg2:

    cur.execute("SELECT * FROM nonexistent")

    print(f"Ошибка SQL: {e}")

 = Лучшие практики:

- Никогда не конкатенировать SQL:

# ХОРОШО:

- Использовать пул соединений:

# для веб-приложений и многопоточных сценариев
