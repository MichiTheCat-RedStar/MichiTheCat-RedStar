 = Декораторы:

- Простой декоратор (без параметров):

def decorator(func):
    def wrapper(*args, **kwargs):
        print("Before")
        result = func(*args, **kwargs)
        print("After")
        return result
    return wrapper

@decorator
def my_function():
    print("Inside")


- Декоратор с параметрами:

def repeat(n):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(n):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def hello():
    print("Hello")


- Сохранение метаданных (functools.wraps):

from functools import wraps

def decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

- Пробел после запятой: [1, 2, 3]
- Две пустые строки между функциями/классами на верхнем уровне
- Одна пустая строка между методами в классе
- Кодировка: UTF-8


 = Советы:

- Используйте f-строки для форматирования (Python 3.6+).
- Для работы с файлами всегда используйте with (контекстный менеджер).
- Используйте list comprehension вместо циклов для создания списков.
- Для проверки на None используйте is / is not (не ==).
- При работе с большими данными используйте генераторы вместо списков.
- Создавайте виртуальные окружения для каждого проекта.
- Для отладки используйте print() или модуль logging.
- Изучайте документацию через help() или dir().
