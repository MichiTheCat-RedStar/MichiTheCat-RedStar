	--- ЧТО ТАКОЕ ИИ ---

 = Суть:

- Определение:

ИИ - это функция, которая подстраивает свои числа,
чтобы ошибаться меньше


- Три уровня сложности:

1. Бинарный поиск			# правило известно заранее
2. Одно обучаемое число		# линейная зависимость
3. Много чисел (нейросеть)	# сложная зависимость


 = Три компонента обучения:

- Параметр w:

Число, которое модель подкручивает


- Ошибка error:

error = правильный_ответ - предсказание


- Скорость обучения lr:

Маленькое число (0.1, 0.01, 0.001)
Показывает, насколько сильно верить ошибке


- Главная строка обучения:

w += lr * error * вход



	--- ОБУЧЕНИЕ ОДНОГО ЧИСЛА ---

 = Линейная модель:

- Формула:

y = w * x


- Полный цикл обучения:

guess = w * x						# предсказание
error = правильный_ответ - guess	# ошибка
w += lr * error * x					# подкрутка


- Смысл словами:

Ошибся в плюс — сдвинь w вверх
Ошибся в минус — сдвинь w вниз
Сдвинь не на всю ошибку, а на маленькую часть (lr)
Чем больше вход x — тем сильнее рычаг


 = Бинарный поиск как частный случай:

- Идея:

guess = 50							# начальная догадка
подсказка = real - guess			# числовая ошибка
guess += lr * подсказка				# сдвиг к правильному


- Отличие от обучения:

В поиске правило известно (диапазон)
В обучении правило неизвестно, находится по примерам



	--- СПАМ-ФИЛЬТР (МНОГО ЧИСЕЛ) ---

 = Идея:

Каждое слово = одно число w
Сумма весов слов письма > 0 → спам


 = Токенизация:

import re

def tokenize(text):
    return re.findall(r"[а-яёa-z]+", text.lower())


 = Предсказание:

def score(text):
    return sum(w.get(word, 0.0) for word in tokenize(text))

def predict(text):
    return 1 if score(text) > 0 else 0


 = Обучение:

lr = 0.1

for epoch in range(20):
    for text, label in data:
        pred = predict(text)
        err = label - pred				# -1, 0 или +1
        if err != 0:
            for word in tokenize(text):
                w[word] = w.get(word, 0.0) + lr * err


 = Что происходит:

Спам-слово встречается часто → вес растёт
Нейтральное слово → вес падает
Правила никто не писал — они вылезли из примеров



	--- СКРЫТЫЙ СЛОЙ (MLP) ---

 = Зачем:

Линейная модель ловит только прямые зависимости
Скрытый слой ловит нелинейные (XOR, изгибы, пороги)


 = Формула:

z1 = X @ W1 + b1						# скрытый слой
a1 = relu(z1)							# активация
z2 = a1 @ W2 + b2						# выход
p  = softmax(z2)						# вероятности классов


 = Активации:

relu(x) = max(0, x)						# простое и рабочее
sigmoid(x) = 1 / (1 + exp(-x))			# для бинарной классификации
softmax(x) = exp(x) / sum(exp(x))		# для многоклассовой


 = Backward (цепное правило):

dz2 = p - onehot(y)						# упрощается для CE
dW2 = a1.T @ dz2
da1 = dz2 @ W2.T
dz1 = da1 * (z1 > 0)					# производная ReLU
dW1 = X.T @ dz1


 = Шаг градиента:

W1 -= lr * dW1
W2 -= lr * dW2



	--- ЧЕК-ЛИСТ: НАПИСАТЬ СВОЙ ИИ ---

 = Порядок действий:

- Шаг 1. Определи вход и выход:

Что подаётся (датчики, текст, пиксели)?
Что должно быть на выходе (класс, число)?


- Шаг 2. Определи, что такое w:

Одно число или много?
Для каждого входа своё w?


- Шаг 3. Определи, откуда брать error:

Готовые метки (спам/не спам)?
Следующий замер датчика?
Финальный результат игры?


- Шаг 4. Напиши цикл:

for пример in данные:
    guess = predict(пример)
    error = правильный_ответ - guess
    w += lr * error * сигнал


- Шаг 5. Подбери lr:

Слишком большой → w прыгает, не сходится
Слишком маленький → учится вечность
Начни с 0.1, уменьшай в 10 раз если не сходится


- Шаг 6. Проверь на отложенных данных:

80% — обучение
20% — проверка (не показывать при обучении)



	--- ЧАСТЫЕ ПРОБЛЕМЫ ---

 = w не сходится:

- Слишком большой lr:

Уменьши в 10 раз


- Данные противоречивы:

Одинаковый вход — разные ответы
Нужно больше признаков или больше слоёв


 = w сходится медленно:

- Слишком маленький lr:

Увеличь в 10 раз


- Мало эпох:

Прогони данные больше раз


 = Модель ошибается на новых данных:

- Переобучение:

Запомнила примеры, не выучила правило
Добавь данных или упрости модель


- Мало данных:

Нужно минимум 10-100 примеров на класс



	--- ПРАКТИЧНЫЕ ИДЕИ БЕЗ ЖЕЛЕЗА ---

 = Простые:

- Спам-фильтр:

Вход: текст, выход: 0 или 1


- Определитель языка:

Вход: короткая фраза, выход: код языка


- Тональность отзывов:

Вход: текст, выход: хорошо/плохо


- Крестики-нолики:

Вход: доска 3x3, выход: лучший ход
Обучение: игра против себя


 = Со датчиками (если есть):

- Предсказание следующего значения:

Вход: текущее + скорость, выход: через 100 мс


- Детектор аномалий:

Вход: датчики, выход: норма/аномалия
Идея: ошибка предсказания > порог


- Классификация жестов:

Вход: акселерометр, выход: влево/вправо/вверх



	--- ЗОЛОТЫЕ ПРАВИЛА ---

 = Помни:

- Всё обучение — это w += lr * error * вход

- Один параметр — один нейрон
Много параметров — сеть

- Сначала if/else, потом обучение
Только когда if/else сломался — учи w

- Одно число — линейная модель
Не хватает — добавь скрытый слой

- Понял на одном числе — понял всё
Остальное просто масштабирование
