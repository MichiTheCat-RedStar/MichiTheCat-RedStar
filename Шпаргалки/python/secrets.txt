	--- ОСНОВНЫЕ КОМАНДЫ SECRETS ---

 = Импорт и базовые функции:

- Импорт модуля:

import secrets


- Генерация случайного целого числа в диапазоне [0, n]:

secrets.randbelow(n)


- Случайное целое число с k случайными битами:

secrets.randbits(k)


- Случайный выбор из последовательности:

secrets.choice(sequence)


- Случайные байты:

secrets.token_bytes(nbytes=None)


- Случайная строка в hex:

secrets.token_hex(nbytes=None)


- Случайная строка URL-safe base64:

secrets.token_urlsafe(nbytes=None)


- Сравнение строк с постоянным временем:

secrets.compare_digest(a, b)


 = Детали по функциям:

- randbelow(n): возвращает число от 0 до n-1. n должно быть больше 0.

- randbits(k): возвращает int с k случайными битами.

- choice(seq): выбирает случайный элемент из непустой последовательности.

- token_bytes(nbytes=None): если nbytes=None, используется значение по умолчанию (32 байта). Возвращает bytes.

- token_hex(nbytes=None): возвращает строку hex, длина в два раза больше nbytes. При nbytes=None длина 64 символа.

- token_urlsafe(nbytes=None): возвращает URL-safe base64 строку. При nbytes=None длина около 43 символов.

- compare_digest(a, b): сравнивает две строки или байта, устойчиво к timing-атакам. Возвращает True, если равны.


 = Примеры использования:

- Генерация пароля:

import secrets
import string
alphabet = string.ascii_letters + string.digits + string.punctuation
password = ''.join(secrets.choice(alphabet) for _ in range(16))


- Генерация токена для сброса пароля:

token = secrets.token_urlsafe(32)


- Генерация API-ключа:

api_key = secrets.token_hex(16)


- Безопасное сравнение:

if secrets.compare_digest(user_token, stored_token):
    print('Доступ разрешён')


- Случайный выбор из списка:

winner = secrets.choice(['Аня', 'Боря', 'Вова'])


- Случайное число от 1 до 100:

number = secrets.randbelow(100) + 1


 = Отличия от random:

- secrets использует криптографически стойкий генератор (CSRNG).

- random использует Mersenne Twister, который предсказуем.

- secrets подходит для паролей, токенов, ключей.

- random подходит для моделирования, игр, не криптографии.

- secrets не имеет seed, состояние не восстановить.

- Функции secrets возвращают только криптостойкие значения.


 = Совместимость и версии:

- Модуль secrets добавлен в Python 3.6.

- В Python 2 используйте os.urandom или random.SystemRandom.

- secrets.compare_digest доступен с Python 3.6.

- token_bytes, token_hex, token_urlsafe — все с Python 3.6.

- DEFAULT_ENTROPY = 32 (байта) для token_* при nbytes=None.


 = Безопасность:

- Всегда используйте secrets для паролей, токенов, ключей.

- Никогда не используйте random для криптографических целей.

- secrets.compare_digest предотвращает timing-атаки.

- Для генерации соли используйте secrets.token_bytes(16).

- Для сессионных идентификаторов используйте token_urlsafe(32).

- Не храните секреты в открытом виде, используйте хеширование.
