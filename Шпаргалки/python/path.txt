--- ОСНОВНЫЕ КОМАНДЫ PATHLIB (PYTHON) ---

 = Импорт и создание:

- Импортировать класс Path:

from pathlib import Path


- Создать объект пути:

Path('/home/user/file.txt')			# абсолютный путь
Path('folder/subfolder/file.txt')	# относительный путь
Path('file.txt')


- Специальные пути:

Path.home()				# домашняя папка пользователя
Path.cwd()				# текущая рабочая директория


 = Оператор объединения (/):

- Соединять части пути через / (как в Unix):

p = Path('/home') / 'user' / 'docs' / 'file.txt'
# Результат: /home/user/docs/file.txt


 = Свойства пути (атрибуты):

- Разложить путь на части:

p = Path('/home/user/docs/file.txt')
p.parent				# /home/user/docs
p.parent.parent			# /home/user
p.name					# file.txt
p.stem					# file (имя без расширения)
p.suffix				# .txt
p.suffixes				# ['.txt']
p.anchor				# / (корень)
p.drive					# '' (для Unix) или 'C:' (для Windows)


 = Проверки (существование и тип):

- Проверить, существует ли:

p.exists()


- Проверить, является ли файлом:

p.is_file()


- Проверить, является ли папкой:

p.is_dir()


- Проверить, является ли абсолютным:

p.is_absolute()


- Проверить, является ли символьной ссылкой:

p.is_symlink()



	--- ПОЛНАЯ ШПАРГАЛКА ПО PATHLIB (И ОСНОВЫ OS.PATH) ---

 = Чтение и запись (просто и быстро):

- Чтение всего текстового файла:

text = Path('file.txt').read_text(encoding='utf-8')


- Запись текста в файл (перезапись):

Path('file.txt').write_text('Hello, world!', encoding='utf-8')


- Чтение бинарного файла:

data = Path('image.png').read_bytes()


- Запись бинарных данных:

Path('image.png').write_bytes(b'\x89PNG...')


 = Навигация и итерация по папкам:

- Получить родительскую папку:

p.parent


- Получить все родительские папки (вверх по иерархии):

list(p.parents)				# [Path('/home/user/docs'), Path('/home/user'), Path('/home'), Path('/')]


- Получить содержимое папки (итератор):

for child in Path('/home/user').iterdir():
    print(child)


 = Создание и удаление (управление файловой системой):

- Создать папку:

p.mkdir()				# создаёт только последнюю папку (родители должны существовать)
p.mkdir(parents=True, exist_ok=True)	# создаёт все промежуточные, не выдаёт ошибку, если уже есть


- Создать пустой файл (обновить время доступа):

p.touch()						# если файл не существует — создаёт


- Переименовать / переместить файл/папку:

p.rename('new_name.txt')		# возвращает новый объект Path
p.replace('new_name.txt')		# заменяет целевой файл, если он существует


- Удалить файл (или символьную ссылку):

p.unlink()						# вызовет ошибку, если это папка
p.unlink(missing_ok=True)		# не выдаёт ошибку, если файла нет (Python 3.8+)


- Удалить пустую папку:

p.rmdir()						# только если папка пуста


- Удалить папку со всем содержимым (через shutil):

import shutil
shutil.rmtree(p)				# рекурсивное удаление


 = Поиск файлов (glob и rglob):

- Найти файлы по шаблону (только в текущей папке):

list(Path('.').glob('*.txt'))	# все .txt в текущей папке
list(Path('.').glob('file?.py'))# file1.py, fileA.py и т.д.


- Рекурсивный поиск (во всех подпапках):

list(Path('.').rglob('*.py'))	# все .py во всех вложенных папках


 = Свойства файлов (информация):

- Получить размер файла (в байтах):

p.stat().st_size


- Получить время последнего изменения (timestamp):

p.stat().st_mtime


- Получить время последнего доступа:

p.stat().st_atime


- Получить время создания (на Unix — время изменения метаданных):

p.stat().st_ctime


- Преобразовать timestamp в datetime:

from datetime import datetime
datetime.fromtimestamp(p.stat().st_mtime)


 = Права доступа и владельцы:

- Изменить права (как chmod):

p.chmod(0o755)				# например, для исполняемого файла


- Получить владельца (имя пользователя):

p.owner()					# только на Unix


- Получить группу владельца:

p.group()					# только на Unix


 = Пути и разрешение (нормализация):

- Получить абсолютный путь (если передан относительный):

p.resolve()					# разрешает все .. и символьные ссылки


- Получить относительный путь от другого пути:

p.relative_to('/home/user')	# если p = /home/user/docs/file.txt, вернёт docs/file.txt


- Проверить, является ли один путь подпутем другого:

Path('/home/user/docs').is_relative_to('/home/user')	# True (Python 3.9+)


- Сравнение путей (лексикографическое и семантическое):

Path('a') == Path('a')		# True
Path('A') == Path('a')		# False (регистр важен на Unix, но не на Windows)


 = Работа с расширениями (суффиксами):

- Добавить суффикс (удобно для изменения расширения):

p.with_suffix('.md')		# file.txt -> file.md
p.with_stem('new_name')		# file.txt -> new_name.txt (Python 3.9+)


- Изменить имя файла:

p.with_name('archive.zip')	# file.txt -> archive.zip


 = Особенности Windows / Unix:

- Pathlib автоматически подстраивается под ОС.
- Для Windows-путей можно использовать слеши `/` (pathlib их правильно преобразует).


 = Альтернатива — os.path (старый стиль):

- Импорт:

import os


- Склеить путь:

os.path.join('folder', 'file.txt')


- Разделить на директорию и имя:

os.path.split('/home/user/file.txt')	# ('/home/user', 'file.txt')


- Получить расширение:

os.path.splitext('file.txt')			# ('file', '.txt')


- Проверить существование:

os.path.exists('file.txt')
os.path.isfile('file.txt')
os.path.isdir('file.txt')


- Получить абсолютный путь:

os.path.abspath('file.txt')


 = Советы:

- Всегда используйте Pathlib для нового кода (чище и удобнее os.path).
- Не забывайте про параметр `encoding` в `read_text`/`write_text` (по умолчанию 'utf-8').
- Для больших файлов используйте обычное открытие через `open(p, 'r')`, а не `read_text`.
