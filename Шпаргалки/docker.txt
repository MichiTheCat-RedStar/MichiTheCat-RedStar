	--- ОСНОВНЫЕ КОМАНДЫ DOCKER ---

 = Управление контейнерами:

- Запустить контейнер из образа:

docker run <образ>		# запуск и вывод в терминал


- Запустить контейнер в фоновом режиме:

docker run -d <образ>	# -d для демона


- Остановить работающий контейнер:

docker stop <контейнер>	# по ID или имени


- Показать все работающие контейнеры:

docker ps				# только запущенные


- Показать все контейнеры (включая остановленные):

docker ps -a


 = Управление образами:

- Скачать образ из реестра:

docker pull <образ>		# например, ubuntu:latest


- Показать все локальные образы:

docker images


- Удалить образ:

docker rmi <образ>		# по ID или имени



	--- ПОЛНАЯ ШПАРГАЛКА ПО DOCKER ---

 = Работа с контейнерами (подробно):

- Запустить контейнер с интерактивной оболочкой:

docker run -it <образ> /bin/bash				# -it для интерактива


- Запустить контейнер с пробросом портов:

docker run -p <хост-порт>:<контейнер-порт> <образ>


- Запустить контейнер с монтированием тома:

docker run -v <хост-путь>:<контейнер-путь> <образ>


- Запустить контейнер с именем:

docker run --name <имя> <образ>


- Остановить все контейнеры:

docker stop $(docker ps -aq)


- Удалить остановленный контейнер:

docker rm <контейнер>


- Удалить все остановленные контейнеры:

docker container prune


- Перезапустить контейнер:

docker restart <контейнер>


- Посмотреть логи контейнера:

docker logs <контейнер>							# добавить -f для слежения


- Выполнить команду в работающем контейнере:

docker exec -it <контейнер> <команда>			# например, /bin/bash


 = Работа с образами (подробно):

- Построить образ из Dockerfile:

docker build -t <имя:тег> <путь к Dockerfile>	# . для текущей папки


- Построить образ без кэша:

docker build --no-cache -t <имя:тег> .


- Сохранить образ в tar-архив:

docker save -o <файл.tar> <образ>


- Загрузить образ из tar-архива:

docker load -i <файл.tar>


- Посмотреть историю слоёв образа:

docker history <образ>


- Удалить образ с принудительным:

docker rmi -f <образ>


- Удалить все неиспользуемые образы:

docker image prune


 = Работа с томами и сетями:

- Создать том:

docker volume create <имя_тома>


- Показать все тома:

docker volume ls


- Удалить том:

docker volume rm <имя_тома>


- Создать сеть:

docker network create <имя_сети>


- Показать сети:

docker network ls


- Подключить контейнер к сети:

docker network connect <сеть> <контейнер>


- Отключить контейнер от сети:

docker network disconnect <сеть> <контейнер>


 = Docker Compose:

- Запустить сервисы из docker-compose.yml:

docker-compose up -d							# -d для фона


- Остановить сервисы:

docker-compose down


- Посмотреть логи всех сервисов:

docker-compose logs


- Пересобрать и запустить:

docker-compose up --build -d


 = Прочее:

- Посмотреть информацию о системе Docker:

docker info


- Очистить всё неиспользуемое (контейнеры, образы, сети, тома):

docker system prune -a							# -a включает все образы


- Войти в реестр Docker:

docker login


- Отправить образ в реестр:

docker push <имя_пользователя>/<образ>:<тег>
