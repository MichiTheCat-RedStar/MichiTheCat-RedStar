	--- ОСНОВНЫЕ КОМАНДЫ DBEAVER ---

 = Подключение к базе данных:

- Открыть мастер нового подключения:

Ctrl+Shift+N			# или Database -> New Database Connection


- Выбрать драйвер:

# в мастере выбрать СУБД (PostgreSQL, MySQL, SQLite и т.д.)


- Заполнить основные поля:

Host: localhost			# адрес сервера
Port: 5432				# порт (зависит от СУБД)
Database: mydb			# имя базы
Username: postgres		# логин
Password: secret		# пароль


- Проверить подключение:

# кнопка Test Connection


- Сохранить подключение:

# кнопка Finish


- Открыть подключение:

F4						# открыть редактор объекта


- Отключиться от базы:

# правый клик по подключению -> Disconnect


 = Работа с SQL-редактором:

- Создать новый SQL-скрипт:

Ctrl+]					# новый скрипт


- Открыть новый SQL-консоль (без файла):

Ctrl+Alt+Enter			# консоль для активного подключения


- Открыть существующий скрипт:

F3						# открыть файл .sql


- Открыть последний скрипт для подключения:

Ctrl+Enter				# последний SQL-скрипт


- Выполнить SQL:

Ctrl+Enter				# выполнить запрос под курсором


- Выполнить весь скрипт:

Ctrl+Alt+Shift+Enter	# выполнить всё, что есть в редакторе


- Форматирование SQL:

Ctrl+Alt+F				# форматировать запрос


- Автодополнение:

Ctrl+Space				# подсказка по коду


- Комментарий строки:

Ctrl+/					# закомментировать / раскомментировать


- Блочный комментарий:

Ctrl+Shift+/			# /* ... */


- Переключение между запросами:

Alt+Up / Alt+Down		# предыдущий / следующий запрос


- Показать план запроса:

Ctrl+Alt+Shift+E		# Explain Plan


- Открыть Visual Query Builder:

Ctrl+B					# визуальный конструктор запросов


- Показать/скрыть SQL в VQB:

Ctrl+Shift+B			# сгенерированный SQL


- Мягкий перенос строк:

Ctrl+Alt+Shift+W		# toggle word wrap


 = Работа с результатами:

- Выбрать все строки (без лимита):

Ctrl+Alt+Shift+A		# fetch all rows


- Следующая страница результатов:

Ctrl+Alt+;				# fetch next page


- Подсчитать количество строк:

Ctrl+Alt+Shift+C		# row count для запроса под курсором


- Фильтр по уникальным значениям:

Ctrl+F11				# filter by unique attribute values


- Сортировка результатов:

Ctrl+2					# toggle sort order (asc/desc/default)


- Переключить Grid / Record view:

Tab						# вид таблицы или записи


- Развернуть панель результатов:

Ctrl+Shift+6			# maximize/normalize results


- Следующая / предыдущая строка:

Ctrl+Alt+Right / Left	# навигация по строкам


- Первая / последняя строка:

Ctrl+Alt+Shift+Left / Right


- Перейти по внешнему ключу:

Alt+Space				# follow foreign key link


- Показать связанные таблицы:

Ctrl+1					# foreign keys and tables referencing current


 = Редактирование данных:

- Добавить строку:

Alt+Insert				# add new row


- Удалить строку:

Alt+Delete				# delete current row


- Дублировать строку:

Ctrl+Alt+Insert			# duplicate current row


- Копировать значение сверху:

Ctrl+D					# copy values from row above


- Копировать значение снизу:

Ctrl+Alt+D				# copy values from row below


- Редактировать ячейку (inline):

Enter					# встроенный редактор


- Редактировать ячейку (диалог):

Shift+Enter				# отдельное окно


- Применить изменения:

Ctrl+S					# apply data changes


- Откатить изменения:

Ctrl+R					# reject data changes


- Установить значение по умолчанию:

Ctrl+Backspace			# set cell to default value


 = Транзакции:

- Зафиксировать изменения:

Ctrl+Alt+Shift+K		# commit в текущей сессии


- Откатить изменения:

Ctrl+Alt+Shift+R		# rollback в текущей сессии


- Режим автокоммита:

# настраивается в Preferences -> Connections


 = Навигация и поиск:

- Поиск по объектам:

Ctrl+H					# Search dialog


- Поиск по файлам в workspace:

Ctrl+Alt+G				# поиск текста в файлах


- Быстрый поиск:

Ctrl+Alt+Shift+F		# Quick search


- Переключение редакторов:

Ctrl+F6					# следующий редактор
Ctrl+Shift+F6			# предыдущий редактор


- Переключение перспектив:

Ctrl+F8					# следующая перспектива


- Переключение вью:

Ctrl+F7					# следующее вью


- Активировать редактор:

F12						# Activate Editor


- Показать контекстное меню:

Alt+`					# database tools menu


- Список редакторов:

Ctrl+E					# editor drop-down list


- Key assist:

Ctrl+Shift+L			# показать все горячие клавиши


 = Утилиты:

- Сгенерировать UUID:

Ctrl+Alt+Shift+U		# UUID/GUID в редактор


- Открыть dashboard:

Ctrl+Alt+Shift+B		# database dashboard


- Выбрать активную схему:

Ctrl+0					# select active schema


- Выбрать подключение для редактора:

Ctrl+9					# select connection


- Показать консоль сервера:

Ctrl+Shift+O			# server output console


- Переключить вертикальные вкладки:

Ctrl+Alt+PageUp/Down	# переключение вкладок
