	--- ОСНОВНЫЕ КОМАНДЫ GIT ---

 = Базовый рабочий цикл:

- Показать состояние репозитория:

git status


- Добавить все изменения в индекс:

git add .


- Добавить конкретный файл:

git add <файл>


- Зафиксировать изменения с сообщением:

git commit -m "Сообщение"


- Отправить изменения в удалённый репозиторий:

git push


- Забрать изменения из удалённого репозитория:

git pull


 = Клонирование и инициализация:

- Создать новый репозиторий в текущей папке:

git init


- Клонировать существующий репозиторий:

git clone <url>


- Клонировать в конкретную папку:

git clone <url> <имя_папки>



	--- ПОЛНАЯ ШПАРГАЛКА ПО GIT ---

 = Работа с ветками:

- Просмотр всех веток (локальных):

git branch


- Просмотр всех веток (включая удалённые):

git branch -a


- Создать новую ветку:

git branch <имя_ветки>


- Переключиться на ветку (старый способ):

git checkout <имя_ветки>


- Переключиться на ветку (новый способ):

git switch <имя_ветки>


- Создать ветку и сразу переключиться:

git checkout -b <имя_ветки>		# или git switch -c <имя_ветки>


- Удалить локальную ветку:

git branch -d <имя_ветки>		# безопасное удаление (слито)
git branch -D <имя_ветки>		# принудительное удаление


- Переименовать текущую ветку:

git branch -m <новое_имя>


- Слить ветку в текущую:

git merge <имя_ветки>


- Отменить слияние (если конфликт):

git merge --abort


 = Работа с удалёнными репозиториями:

- Показать удалённые репозитории:

git remote -v


- Добавить удалённый репозиторий:

git remote add <имя> <url>


- Удалить удалённый репозиторий:

git remote remove <имя>


- Переименовать удалённый репозиторий:

git remote rename <старое> <новое>


- Забрать изменения без слияния:

git fetch <удалённый>


- Забрать изменения и слить (аналог pull):

git pull <удалённый> <ветка>	# обычно git pull origin main


- Отправить изменения в удалённый репозиторий:

git push <удалённый> <ветка>	# обычно git push origin main


- Отправить и установить upstream (привязку):

git push -u origin <ветка>


- Удалить ветку в удалённом репозитории:

git push origin --delete <ветка>


 = Отмена изменений и восстановление:

- Отменить изменения в рабочем каталоге (для файла):

git restore <файл>	# или git checkout -- <файл>


- Отменить изменения в индексе (снять с добавления):

git restore --staged <файл>		# или git reset HEAD <файл>


- Отменить последний коммит (оставить изменения в рабочем каталоге):

git reset --soft HEAD~1


- Отменить последний коммит (удалить изменения из индекса, но оставить в рабочем каталоге):

git reset --mixed HEAD~1		# (по умолчанию)


- Отменить последний коммит (полностью удалить изменения):

git reset --hard HEAD~1


- Отменить коммит, создав новый коммит с обратными изменениями (безопасно для публичных веток):

git revert <хэш_коммита>


- Временно сохранить незакоммиченные изменения:

git stash


- Применить последний stash и удалить его:

git stash pop


- Применить последний stash без удаления:

git stash apply


- Показать список stash:

git stash list


 = Просмотр истории и сравнение:

- Показать историю коммитов:

git log


- Показать историю в сокращённом виде (одна строка на коммит):

git log --oneline


- Показать историю с графом ветвления:

git log --graph --oneline --decorate


- Показать изменения между коммитами:

git diff <коммит1> <коммит2>


- Показать изменения в рабочем каталоге относительно индекса:

git diff


- Показать изменения в индексе относительно последнего коммита:

git diff --staged


- Показать изменения конкретного файла:

git diff <файл>


 = Конфигурация и прочее:

- Установить имя пользователя (глобально):

git config --global user.name "Ваше Имя"


- Установить email (глобально):

git config --global user.email "email@example.com"


- Просмотреть текущие настройки:

git config --list


- Открыть глобальный конфиг в редакторе:

git config --global --edit


- Игнорировать файлы (создать .gitignore):

echo "node_modules/" >> .gitignore


- Показать все теги:

git tag


- Создать лёгкий тег:

git tag <имя_тега>


- Создать аннотированный тег:

git tag -a <имя_тега> -m "Сообщение"


- Отправить теги в удалённый репозиторий:

git push --tags


- Удалить локальный тег:

git tag -d <имя_тега>
