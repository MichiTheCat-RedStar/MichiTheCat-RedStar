	--- ОСНОВЫ STABLE DIFFUSION ---
 = Ключевые понятия:
- Термины:
latent diffusion		# генерация в латентном пространстве VAE, а не напрямую в пикселях
checkpoint				# основная модель: text encoder + UNet + VAE
sampler					# метод шаговой деноизации: Euler, DPM++, UniPC и т.д.
scheduler				# расписание шагов/шума: Karras, Normal, Exponential
guidance_scale			# CFG: насколько сильно модель следует промпту
seed					# зерно начального шума; фиксированный seed помогает воспроизводить
strength				# для img2img/inpaint: сколько исходника перерисовать
clip_skip				# пропуск последних слоёв CLIP; 2 часто для аниме/стилевых моделей
negative_prompt			# условия, которые модель должна подавлять
batch_size				# сколько изображений генерировать за один проход
n_iter					# сколько батчей подряд генерировать
denoising_strength		# в UI часто то же, что strength для img2img/inpaint


 = Форматы файлов:
- Модели и веса:
.safetensors			# предпочтительно: безопаснее, быстрее, без pickle
.ckpt					# старый формат; может содержать исполняемый pickle
.gguf					# квантизованные веса; удобны для CPU/слабых GPU
vae.safetensors			# отдельный VAE для цвета/резкости
lora.safetensors		# лёгкая дообученная надстройка: стиль, персонаж, объект
embedding.pt			# textual inversion / концепт-токен
controlnet.safetensors		# условный контроль по краям, позе, глубине и т.д.
workflows.json			# графы ComfyUI; не путать с обычным checkpoint


 = Поколения и размеры:
- Нативные разрешения:
SD 1.5					# нативно 512x512; размеры кратные 8; 512x768/768x512 осторожно
SD 2.x base				# часто 768x768; менее популярна, чем SD 1.5
SD 2.x depth/inpaint	# специализированные версии для глубины/маски
SDXL					# нативно 1024x1024; требует больше VRAM, чем SD 1.5
SD 3 / SD 3.5			# flow matching; отдельные pipeline и текстовые энкодеры
LCM / Turbo				# дистиллированные версии; 1-8 шагов, низкий CFG


- SDXL пропорции:
1024x1024			# квадрат
1216x832			# ландшафт
832x1216			# портрет
1344x768			# широкий ландшафт
768x1344			# высокий портрет

 = Text-to-image SD 1.5:
- Минимальный скрипт:
import torch
from diffusers import StableDiffusionPipeline, DPMSolverMultistepScheduler
device = "cuda" if torch.cuda.is_available() else "cpu"
dtype = torch.float16 if device == "cuda" else torch.float32
pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    torch_dtype=dtype,
    use_safetensors=True,
)
pipe.scheduler = DPMSolverMultistepScheduler.from_config(
    pipe.scheduler.config,
    solver_order=2,
    algorithm_type="dpmsolver++",
    use_karras_sigmas=True,
)
if device == "cuda":
    pipe.enable_model_cpu_offload()		# мало VRAM; не делай pipe.to("cuda") одновременно
else:
    pipe.to("cpu")
image = pipe(
    prompt="cinematic portrait of a cat astronaut, soft rim light, 85mm",
    negative_prompt="blurry, extra limbs, watermark, text",
    width=512,
    height=512,
    num_inference_steps=28,
    guidance_scale=7.0,
    generator=torch.Generator(device).manual_seed(42),
).images[0]
image.save("out.png")

 = Шаблон промпта:

- Пример:

 = Negative prompt:
- Базовый набор:
lowres, bad anatomy, bad hands, extra fingers, missing limbs, extra limbs, deformed, disfigured, blurry, jpeg artifacts, watermark, text, signature, username, oversaturated, worst quality


 = Веса в A1111/Forge:
- Синтаксис:
(keyword:1.2)		# усилить

 = Приёмы промптинга:
- Практические:
ранние токены важнее		# ставь главное в начало
короче чаще лучше			# не сваливай 50 тегов без структуры
описывай цель, не список	# "wet asphalt reflecting neon" вместо "rain, city, neon, reflection"
один стиль за раз			# смешение многих художников размывает результат
для лиц						# eyes, skin texture, lighting
для рук						# hands, fingers, pose, negative prompt, ControlNet
для композиции				# camera angle, lens, framing, depth of field


 = Быстрые пресеты:
- Настройки:
черновой			# 15-20 шагов, CFG 5-6, Euler a / DPM++ 2M Karras
баланс				# 25-35 шагов, CFG 6-8, DPM++ 2M Karras / UniPC
жёсткий промпт		# 30-40 шагов, CFG 8-12, DPM++ 2M / DDIM
LCM/Turbo			# 4-8 шагов, CFG 1-2, LCMScheduler / Euler a
аниме/стиль			# 20-30 шагов, CFG 6-8, clip_skip 2
фотореализм			# 30-40 шагов, CFG 5-7, clip_skip 1-2, детали кожи/света

 = Inpaint:

лучше использовать inpaint-модель, а не обычный checkpoint

	--- ЭКОНОМИЯ РЕСУРСОВ ---
 = Слабый GPU/CPU:
- Что снижать первым:
модель				# SD 1.5 вместо SDXL; LCM/Turbo вместо обычных
размер				# 512x512 или 512x768; не гнаться за 2K нативно
шаги				# 15-25 для DPM++, 4-8 для LCM/Turbo
CFG					# 5-7; высокий CFG иногда требует больше шагов
precision			# fp16 на CUDA; bf16 на новых GPU; float32 на CPU
offload				# enable_model_cpu_offload / sequential_cpu_offload
slicing				# enable_attention_slicing, enable_vae_slicing
tiling				# enable_vae_tiling для больших изображений
quantization		# GGUF для stable-diffusion.cpp; 4-bit UNet если поддерживается

 = AMD / старое железо:
- Практические варианты:

DirectML / ONNX			# альтернатива на Windows/AMD, но меньше совместимости

 = Стабильность и повторимость:
- Правила:
seed фиксировать при итерациях промпта
менять один параметр за раз
сохранять parameters/info из ответа UI/API
для серий использовать batch_size/n_iter, но не слишком большой batch
generator device должен совпадать с device pipeline

битый checkpoint/VAE
неподходящий sampler для модели
слишком высокий CFG + мало шагов
попробовать DPM++ 2M Karras, 28-35 шагов, CFG 6-8


 = Размытие:
- Причины и лечение:
мало шагов				# увеличить 25-35
низкий CFG				# поднять 6-8
слишком большой размер	# генерировать в нативном разрешении, потом upscale
плохой промпт			# добавить sharp focus, detailed, lighting
анцестровый sampler		# Euler a может быть мягче; попробуй DPM++/UniPC


 = Деформации:
- Причины и лечение:
extra limbs/faces		# negative prompt, lower CFG, ControlNet/openpose
bad hands				# inpaint рук, hand refiner, ControlNet depth/canny
too many objects		# упростить промпт, разбить на части
face collapse			# clip_skip 1-2, уменьшить CFG, добавить lighting/texture
